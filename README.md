# Fallstudie zu IPWA01-01 – Programmierung von Webanwendungsoberflächen

Dieses Repository enthält meine Umsetzung der **Kleiderspenden-Registrierung** (Aufgabenstellung 3).  
Das Projekt habe ich im Rahmen der Fallstudie für das Modul IPWA01-01 entwickelt.

## Funktionen
- Registrierung von Kleiderspenden über ein Formular
- Auswahl zwischen **Übergabe an der Geschäftsstelle** oder **Abholung durch Sammelfahrzeug**
- Postleitzahl-Prüfung bei Abholung (erste zwei Ziffern müssen übereinstimmen)
- Bestätigungsseite mit einer Übersicht aller eingegebenen Daten
- Responsives Layout mit **Tailwind CSS**, optimiert für Desktop und mobile Geräte

## Nutzung
1. Das Repository klonen oder als ZIP herunterladen.  
2. Die Datei `index.html` im Browser öffnen.  
   → Die Anwendung läuft komplett im Browser, ein Server ist nicht erforderlich.

## Technologien
- HTML5
- Tailwind CSS (eingebunden per CDN)
- JavaScript (Vanilla, ohne Frameworks)
